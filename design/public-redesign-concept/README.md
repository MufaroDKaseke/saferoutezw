# SafeRouteZW public site redesign concept (prototype, synthetic data)

Design exploration only. Nothing here is imported by the app and no production page, API or model was changed.

- `current-site-screenshots/`: headless Chrome captures of the running app (2026-11-04), desktop 1440px plus one narrow capture.
- `artboards/`: the concept artboards (`*.dc.html`) and `canvas.json` layout, as published to the design canvas.
- `build/`: Python generators and `srz.css` (design tokens and components). Run a page script from this folder, for example `python p_home.py`.

All incidents, times, distances and counts in the artboards are sample data.
